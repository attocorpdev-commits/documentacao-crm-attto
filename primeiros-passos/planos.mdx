O CRM da Atto Corp tem três planos: **Start**, **Prime** e **Ultra**.

Start e Prime você assina sozinho, direto na tela de planos. O **Ultra** é sob medida: ele é montado para a sua operação e contratado falando com o time da Atto.

Esta página mostra o que cada plano inclui, igual à comparação que aparece no CRM. Para gerenciar a sua assinatura, veja [Planos e cobrança](/conta/planos).

<Note>
  Esta página não traz preços. Para ver os valores, acesse [attocorp.com/#planos](https://attocorp.com/#planos).
</Note>

## Comparação item a item

As tabelas abaixo seguem a comparação da tela de planos, grupo por grupo. ✓ significa incluído e ✗ significa não incluído.

### Atendimento

| Recurso | Start | Prime | Ultra |
| --- | :---: | :---: | :---: |
| Agente IA responde 24/7 | ✓ | ✓ | ✓ |
| Separa quem tá pronto pra fechar | ✓ | ✓ | ✓ |
| Time assume a conversa com um clique | ✓ | ✓ | ✓ |
| Explica seu produto e tira dúvida sem você repetir | ✓ | ✓ | ✓ |

- **Agente IA responde 24/7**: sem fila e sem horário. Se a cota do mês acabar e não houver pacote extra, a IA pausa o atendimento até a renovação ou a compra de um pacote.
- **Separa quem tá pronto pra fechar**: a IA lê a conversa e classifica pelo interesse que a pessoa demonstra. Não é palavra-chave nem regra fixa. Quando a venda fecha fora da conversa (presencial ou por ligação), a IA não tem esse dado.
- **Explica seu produto e tira dúvida sem você repetir**: funciona a partir da base de conhecimento que você alimenta, como produto, preço, política e objeções comuns. Quanto melhor o material, melhor a resposta. Veja [Agente IA](/ia/agente-ia).

### Volume

| Recurso | Start | Prime | Ultra |
| --- | :---: | :---: | :---: |
| Conversas por mês | Cota do plano | Cota do plano | Ilimitadas, número do plano ou sob escopo |
| Pacotes extras de conversa | ✓ | ✓ | ✓ |

- **Conversas por mês**: na tela, cada plano mostra o número de conversas da cota. 1 conversa é 1 contato dentro de uma janela de 24 horas. Se o mesmo contato voltar no dia seguinte, conta de novo. No Ultra o volume é sob medida: a tela mostra **Ilimitadas** quando não há cota fixa.
- **Pacotes extras de conversa**: você é avisado quando chega perto do limite do mês. O pacote extra é cumulativo e não expira. Veja [Conversas e créditos de IA](/ia/creditos).

### Funil

| Recurso | Start | Prime | Ultra |
| --- | :---: | :---: | :---: |
| Gestão de contatos | ✓ | ✓ | ✓ |
| IA move o contato conforme avança | ✗ | ✓ | ✓ |

- **Gestão de contatos**: funil no formato kanban, com etapas e gatilhos que você configura.
- **IA move o contato conforme avança**: a IA lê a conversa e muda o contato de etapa. Não é aleatório nem regra fixa. Quando a venda fecha fora da conversa, a IA não tem esse dado.

### Canais

| Recurso | Start | Prime | Ultra |
| --- | :---: | :---: | :---: |
| WhatsApp (QR Code) | ✓ | ✓ | ✓ |
| API oficial Meta | ✓ | ✓ | ✓ |
| Números de WhatsApp inclusos | 1 | 1 | sob escopo |
| Instagram Direct | ✗ | add-on | 2 inclusos |

- **API oficial Meta**: é o tipo **WhatsApp Oficial (Meta)**. Não tem risco estrutural de banimento do número. O risco existe só se você descumprir as regras de uso da Meta. Veja a diferença em [Tipos de WhatsApp](/primeiros-passos/tipos-whatsapp).
- **Números de WhatsApp inclusos**: Start e Prime vêm com 1 número de WhatsApp cada. No Ultra, a quantidade é definida sob escopo. Precisa de mais números? Fale com a gente.
- **Instagram Direct**: é um canal separado, com cota própria, e não ocupa os números de WhatsApp. É um item extra dos planos Prime e Ultra. No Ultra já vêm 2 canais inclusos. Não está disponível no Start. Veja [Instagram](/atendimento/instagram).

### Agenda

| Recurso | Start | Prime | Ultra |
| --- | :---: | :---: | :---: |
| Agenda para marcar | ✓ | ✓ | ✓ |
| Envia link de pagamento | ✓ | ✓ | ✓ |
| Avisa o time quando o contato está pronto | ✓ | ✓ | ✓ |

- **Agenda para marcar**: o Start tem a Agenda completa, com página, marcação manual e Google Calendar. O que é exclusivo do Prime é a IA marcar sozinha, a partir da conversa, sem ninguém digitar.
- **Envia link de pagamento**: a IA envia o link quando está configurada e treinada para isso.
- **Avisa o time quando o contato está pronto**: o aviso chega por WhatsApp e dentro do CRM. No Start, você é avisado de lead novo e de quem demonstrou interesse (quando a pessoa pergunta sobre o produto ou serviço). No Prime, também de lead qualificado, de quem está sem resposta e de quem recebeu link.

### Dados

| Recurso | Start | Prime | Ultra |
| --- | :---: | :---: | :---: |
| Dashboard e métricas em tempo real | ✓ | ✓ | ✓ |
| Relatório em linguagem de dono | ✗ | ✓ | ✓ |

- **Dashboard e métricas em tempo real**: volume de contatos, quando chegaram, quando as mensagens foram enviadas, movimentação no Pipeline no dia e valor da negociação.
- **Relatório em linguagem de dono**: as principais objeções do período e os argumentos que mais funcionaram.

### Confiança

| Recurso | Start | Prime | Ultra |
| --- | :---: | :---: | :---: |
| Membros do time | ilimitados | ilimitados | ilimitados |
| Sem taxa de ativação | ✓ | ✓ | ✓ |

Para convidar pessoas e definir o que cada uma pode fazer, veja [Equipe](/conta/equipe).

### Só no Sob medida

| Recurso | Start | Prime | Ultra |
| --- | :---: | :---: | :---: |
| Auditoria semanal das conversas | ✗ | ✗ | ✓ |
| Follow-up de quem parou de responder | ✗ | ✗ | ✓ |
| Integração com API ou serviço externo | ✗ | ✗ | ✓ |
| Escopo e volumes sob diagnóstico | ✗ | ✗ | ✓ |

- **Integração com API ou serviço externo**: o Ultra se adapta à sua operação. Dá para sincronizar com o seu sistema de gestão, outro CRM ou outro serviço. O escopo é definido junto com o time.

## Mensal ou anual

No alto da tela de planos você escolhe entre **Plano mensal** e **Plano anual**.

- **Plano mensal**: a cobrança é todo mês, como assinatura. O card mostra **sem taxa de ativação · cancele quando quiser**.
- **Plano anual**: a cobrança é única, à vista, no cartão ou no PIX, e vale 12 meses. O valor equivale a 10 mensalidades, por isso o card mostra **2 meses grátis** e o percentual de desconto. O plano anual não renova sozinho.

<Note>
  O valor mensal mostrado no **Plano anual** é o total do ano dividido por 12. Os valores aparecem em [attocorp.com/#planos](https://attocorp.com/#planos).
</Note>

Já assina o mensal? Você pode trocar para o anual. Veja [Trocar do mensal para o anual](/conta/planos#trocar-do-mensal-para-o-anual).

Para assinar qualquer plano, marque **Li e aceito os Termos de Uso e a Política de Privacidade.**, abaixo dos planos.

## Teste grátis de 7 dias

O botão **Teste por 7 dias Grátis** aparece no Start e no Prime para quem nunca teve plano, e só no **Plano mensal**.

- O teste vale uma vez por conta.
- No **Plano anual** não há teste: o botão é **Assinar este plano**.
- Quem já assina vê **Mudar para este plano**. Quem já teve plano vê **Assinar este plano**.

O Ultra não tem teste grátis. O botão dele é **Falar com o time**, que abre uma conversa no WhatsApp com o time da Atto.

## Itens extras

- **Conversas**: se a cota do mês acabar, você compra um pacote extra de conversas. Veja como em [Planos e cobrança](/conta/planos) e [Conversas e créditos de IA](/ia/creditos).
- **Instagram Direct**: item extra nos planos Prime e Ultra. O Ultra já inclui 2 canais.
- **Números de WhatsApp**: Start e Prime incluem 1 número. Para mais números, fale com a gente pelo [Suporte](/empresa/suporte).
- **Membros**: ilimitados em todos os planos.
- **Empresas**: se a tela mostrar **Plano para a empresa:**, cada empresa tem o seu próprio plano. Escolha a empresa antes de assinar.

## Como trocar de plano

A troca de plano fica em **Meu Perfil > Assinatura > Trocar de plano**. Subir de plano vale na hora. Reduzir fica agendado para o fim do ciclo. O passo a passo completo está em [Planos e cobrança](/conta/planos).

## Perguntas frequentes

<AccordionGroup>
  <Accordion title="Qual a diferença entre o Start e o Prime?">
    Os dois respondem, qualificam e entregam a conversa ao time. No Prime a IA também move o contato de etapa no Pipeline, marca na agenda sozinha a partir da conversa e você recebe o **Relatório em linguagem de dono**. O Prime também avisa mais tipos de evento ao time e permite o Instagram Direct como item extra.
  </Accordion>
  <Accordion title="O que conta como uma conversa?">
    1 contato atendido pela IA dentro de uma janela de 24 horas. Se o mesmo contato voltar no dia seguinte, conta como uma nova conversa. Veja [Conversas e créditos de IA](/ia/creditos).
  </Accordion>
  <Accordion title="As conversas que sobram passam para o mês seguinte?">
    A cota do mês não passa para o mês seguinte. Já o pacote extra de conversas é cumulativo e não expira.
  </Accordion>
  <Accordion title="O que acontece se as conversas do mês acabarem?">
    Você é avisado antes de chegar no limite. Se a cota acabar e não houver pacote extra, a IA pausa o atendimento até a renovação ou a compra de um pacote.
  </Accordion>
  <Accordion title="O plano Start tem Instagram?">
    Não. O Instagram Direct é um item extra dos planos Prime e Ultra. Veja [Instagram](/atendimento/instagram).
  </Accordion>
  <Accordion title="Como contrato o Ultra?">
    Na tela de planos, clique em **Falar com o time** no card do Ultra. Abre uma conversa no WhatsApp com o time da Atto, que monta o escopo com você.
  </Accordion>
</AccordionGroup>
